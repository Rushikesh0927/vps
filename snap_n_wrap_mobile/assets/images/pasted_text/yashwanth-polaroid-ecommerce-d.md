Design Goal

Design a modern premium e-commerce website for Yashwanth Customized Printings, allowing customers to upload, customize, preview, and order high-quality Polaroid photo prints.

The design should feel premium, minimal, emotional, elegant, and photography-focused, similar in quality to Apple, Framer, Stripe, Notion, and Linear.

The website must be fully responsive with separate optimized layouts for Desktop (1440px) and Mobile (390px).
